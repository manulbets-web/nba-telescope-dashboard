# NBA Telescope partner dashboard

Read-only, publicly shared sportsbook-implied combination-market analysis.
The site is regenerated locally from frozen prediction snapshots.
The public repository intentionally contains **only the webpage**.
No original sportsbook files, player-level confirmed betting records,
API keys, model source code, or internal history database are tracked here.

The published model signals and prices are research observations,
not endorsements or evidence of available offers or actual fills.
